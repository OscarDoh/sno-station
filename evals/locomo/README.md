# LoCoMo

LoCoMo measures question answering over long conversations. Higher accuracy is better.

This receipt covers all 1,542 answerable questions in `locomo10`. It is a merged final-answer set:
the full benchmark ran first, then only questions still wrong were answered again after fixes.
Already-correct questions were carried forward, so this is not a single-run score.

Result: **1,492 / 1,542, 96.76%**.

The complete [merged final-answer set](formal-run-2026-09-18/) contains all 1,542
questions, responses, reasoning records, verdicts, and the run that supplied each accepted answer.

The public harness is not included yet, so no public rerun command is claimed.
