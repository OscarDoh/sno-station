# Memora

Memora measures both recall and whether superseded facts are correctly forgotten. FAMA, MPA and
FAA are higher-is-better; forgetting penalty is lower-is-better.

This receipt covers the weekly track: six personas, fifteen questions each, ninety questions in
total.

- **FAMA:** 87.2
- **MPA:** 0.9096
- **FAA:** 0.8334
- **Forgetting penalty:** 3.76 points

The complete [formal-run evidence](formal-run-2026-09-06/) includes all ninety assembled
questions, recalled memories, final answers, per-judge judgments, and per-question scores.

The comparison in the root README is directional because our run and the paper's systems did not
use the same judge stack. The public harness is not included yet, so no public rerun command is
claimed.
