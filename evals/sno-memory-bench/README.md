# Sno Memory Bench

Sno Memory Bench is a first-party end-to-end corpus covering extraction, preferences, updates,
multi-session reasoning, temporal reasoning and correct abstention.

The adopted run passed **23 of 23 probes (100%)**. This is a product-specific floor, not an
independent comparison with another memory system.

The complete [formal-run evidence](formal-run-2026-06-16/) contains all 23 questions, replies,
verdicts, reasons, raw model responses, category scores, and run metadata.

The public harness is not included yet, so no public rerun command is claimed.
